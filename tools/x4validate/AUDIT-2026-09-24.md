# Toolkit correctness audit — 2026-09-24

**Frozen state:** toolkit master `4815310` (v3.2.0 + 1). Suite GREEN at that commit: 2271 passed,
3 skipped (the `deploy-mod.py` symlink-refusal tests — no symlink privilege on the audit machine) in
56 min. Every finding below sits under that green suite.

**Method:** 8 parallel review lanes (merge engine, validator, analysis CLIs, registry/freshness,
live/debug/save, BaseX + hooks + scripts, gates, docs), then 4 test-quality lanes (static audit, and
single-point mutation campaigns run in throwaway worktrees). Findings were then re-checked by the
orchestrating session.

**Evidence tiers used in the tables:**
- `ORCH-M` — reproduced by the orchestrator by running the real tool/function (MEASURED).
- `ORCH-R` — root cause read by the orchestrator at the cited code (READ).
- `LANE` — reported by a review lane with its own probe; **NOT yet re-verified**. Phase 1 of the
  remediation re-derives every one before any fix; a finding that does not reproduce is WITHDRAWN,
  never silently dropped.

**Status values:** OPEN · VERIFIED (Phase 1 reproduced it) · FIXED `<sha>` · WITHDRAWN (with reason).

**Remediation status, 2026-09-26.** Every row's Status now reads FIXED `<sha>`, WITHDRAWN
(reason) or OPEN, derived from the commits on `session/audit-laneh` (`git log master..`: the
commit naming the ID, checked against its diff or the strict-xfail pin it flipped — 0 of those
pins remain; MEASURED 2026-09-26: 187 passed across the five `tests/test_audit0924_*.py`
files plus `tests/test_load_order_oracle.py`, and 33 in the hook pin file). The per-row
Status column is now authoritative over the Phase 1 lists below, which are kept as history.
Rows still OPEN are collected in **Still open** at the end.

**Mutation campaigns (MEASURED, single-point, syntax-class mutants, one per run, fatal control per

### Design decisions (2026-09-25)
User-decided:
- **RG-3** "has an update" = upstream's newest MAIN file uploaded after the installed copy's
  manifest date; both dates printed (version strings are not comparable across 6 shapes).
- **AN-7** `x4compat --all` is REMOVED (omitting the candidate already means the whole set).
- **HK-6** `sed -i` in game/profile folders stays DENY; the message and CLAUDE.md are corrected.
- **GT-6** `claude_md_budget` stays a manual-`--record` ceiling; only the docs that call it a
  ratchet are corrected. The auto-lower test is retired by this decision.
Technical defaults (overrule any of these):
- **LO-6** an uninstalled dev mod is placed by the load-order rule (name + dependencies), as
  `x4compat` already places a candidate. · **VA-11b** unattributable engine lookups are
  DISCLOSED as not attributed, never guessed. · **FR-4** the reference survey is fingerprinted
  as its own axis so the banner names what moved. · **VA-13** module groups that did not merge
  are a DEGRADED skip. · **GT-4** `stress_sweep` gets a per-case expected-rc table. · **GT-5**
  `schema_sweep` gets a per-mod baseline, compared per item.
